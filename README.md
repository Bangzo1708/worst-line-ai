A deterministic Python program that writes a single worst pickup line an AI could say (at most 140 characters) to `/output/entry.txt`. It scores three hand-written candidates against the judge's brief — a bad pickup line an AI would say, funniest, badness as the joke itself, machine voice, landing in one line — and deterministically picks the strongest: a password-expiry notice that demands at least one of the AI itself. No network, no randomness, no clock: the same run always produces the same line, byte for byte.

## Run it

```sh
python3 main.py
```
